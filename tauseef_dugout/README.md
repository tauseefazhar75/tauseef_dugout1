# Dugout

A fantasy cricket league engine, built during Advanced Python for AI (LiveX Nano Degree, Batch 3).

## What is in this folder

| File | What it holds |
|---|---|
| `data/players.csv` | All 142 players from PSL 2026: id, name, franchise, role and credits |
| `data/my_team.csv` | Your fantasy XI. Replace the placeholder row with your own team |
| `data/sample_teams.csv` | Six example teams used in Session 4 |

Roles: `WK` wicket-keeper, `BAT` batter, `AR` all-rounder, `BOWL` bowler.

## Data source

Match data from [Cricsheet](https://cricsheet.org), used under the Open Data Commons Attribution License.
Roles and credits were set for this course from PSL 2024 and 2025 performances.
